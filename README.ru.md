# Banner Saga FPS Fix

Убирает сильную просадку FPS при открытии карточки/экрана прокачки героя в **The Banner Saga 1**, останавливая анимацию портрета на этом экране. Сам портрет остаётся видимым и статичным. Мод не обещает повышения FPS во всей игре.

Проверено на **Steam Windows 2.58.17 / build 3268685**, русский язык. В испытанной конфигурации FPS на проблемном экране восстановился примерно с 20 до 100. Это результат одного пользователя, а не универсальный замер. Другие версии и продолжения первым профилем не поддерживаются.

## Установка

1. Закройте The Banner Saga.
2. Распакуйте архив патчера вне папки игры и запустите `BannerSagaFPSFix.exe`. Нужна Windows 10/11 с .NET Framework 4.8.
3. Выберите папку игры, содержащую `win32`, и нажмите **Проверить**.
4. Если исходный файл поддерживается, нажмите **Установить фикс**.
5. Запускайте игру обычным способом через Steam.

Переключатель языка вверху выбирает русский или английский интерфейс. Python и декомпилятор пользователю не нужны. Изменяется только `win32/app.game-saga1.air.swf`; сохранения, локализация, настройки Steam и Windows не редактируются. Патчер не запускает и не завершает игру.

## Откат

Закройте игру, откройте патчер, выберите ту же папку и нажмите **Восстановить оригинал**. Проверенная резервная копия хранится в `.BannerSagaFPSFix/original.swf` внутри игры. Пока фикс установлен, не удаляйте эту папку. Копия проверяется перед откатом и сохраняется после него; операции можно повторять.

Если после установки файл изменил другой мод или обновление, патчер откажется его затирать. Если фикс установлен вручную и у патчера нет резервной копии, он покажет это состояние; для отката нужен прежний способ установки. Оригинальный файл не скачивается и не создаётся из неизвестных данных.

## Совместимость и исходники

Для установки принимается только проверенный оригинальный SWF. Другие версии и моды, меняющие тот же файл, пока не поддерживаются. Проверка файлов Steam и обновление игры могут снять фикс; после них можно проверить состояние заново. Другие языки не изменяются, но игровая проверка выполнена только на русском.

Исходники — MPL-2.0. В архиве нет игровых файлов или ассетов; см. `LICENSING.md`. Для сборки из исходников нужны Git и штатный C#-компилятор .NET Framework: `tools/test.ps1`, затем `tools/build.ps1 -OutDirectory ./local/candidates/0.1.0-test.1`. Версией управляет `VERSION`. Команды `--status`, `--install`, `--restore` принимают путь к папке игры.

Текущий пакет — тестовый кандидат до приёмки интерфейса установщика. Публикации на Nexus и стабильного релиза пока нет.
